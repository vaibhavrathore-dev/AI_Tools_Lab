# AI Tools Lab

A Python project created as part of the **Artificial Intelligence Tools and Applications Lab (AGCS-25308)**.

This repository demonstrates the use of Git, GitHub, version control workflows, sorting algorithms, utility functions, and AI-assisted software development.

## Features

- Bubble Sort implementation
- Palindrome checker
- Word counter
- Celsius to Fahrenheit converter
- Git branching and feature development
- Pull Request workflow
- AI-assisted code generation and documentation

## Project Structure

```text
AI_Tools_Lab/
├── README.md
├── hello.py
├── sorting.py
└── utils.py
```

## Installation

Clone the repository:

```bash
git clone https://github.com/vaibhavrathore-dev/AI_Tools_Lab.git
```

Enter the project directory:

```bash
cd AI_Tools_Lab
```

Make sure Python 3 is installed:

```bash
python3 --version
```

## Usage

### Hello Program

```bash
python3 hello.py
```

### Bubble Sort

```bash
python3 sorting.py
```

### Utility Functions

The `utils.py` module provides:

```python
is_palindrome("madam")
count_words("Artificial Intelligence Tools Lab")
celsius_to_fahrenheit(25)
```

Example results:

```text
True
4
77.0
```

## Git Workflow

This project demonstrates a feature-branch workflow:

```text
main
 ├── feature/sorting
 └── feature/utils
```

Features are developed separately and merged into `main` using GitHub Pull Requests.
